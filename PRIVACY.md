# Datenschutz / Privacy

## Deutsch

FocusFlow sendet nur nach ausdrücklicher Zustimmung anonyme Nutzungs- und Absturzdiagnosen an PostHog EU. Gesendet werden ausschließlich freigegebene Zähler, Zustände, App-Version, macOS-Version, Architektur und Sprache sowie technische Absturzwerte. Es werden keine Inhalte, Namen, Titel, Notizen, Domains, URLs, Bundle-IDs, App-Namen, Projekt-/Todo-IDs, Dateipfade oder freien Fehlermeldungen gesendet.

## English

FocusFlow sends anonymous usage and crash diagnostics to PostHog EU only after explicit consent. It sends only approved counts, states, app version, macOS version, architecture and language, plus technical crash values. It never sends content, names, titles, notes, domains, URLs, bundle IDs, app names, project or todo IDs, file paths, or free-text errors.
